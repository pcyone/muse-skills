# Hand Post Copy Scope Check

## Check the production record first

- Read the production record for the exact video before you draft or revise any copy that describes how the video was made.

- List each part separately in your working notes, such as copy, visuals, narration, and subtitles, and record the source shown for each part.

- Treat a part with no recorded source as unverified, and do not assign it to any tool in the copy.

- Check every draft in a series against its own production record, because a correction to one draft does not prove the next draft is correct.

## Scope each production claim to verified parts

- Write a whole work claim only when the record shows the same source produced every part named in the claim.

- Name only the parts the record verifies for that source, and leave every other part out of the claim.

- Drop a broad phrase such as fully produced by one tool when any part came from another tool, and replace it with the verified parts only.

- Keep a claim about copy, visuals, and subtitles separate from a claim about narration when the record attributes narration elsewhere.

## Check the literal scope strings before delivery

- Search the final draft for the exact substring 全自动制作 before you deliver it, because that substring is the recurring slip.

- Search the final draft for the exact string 文案、画面、字幕由 Muse 全自动制作 and treat any match as a failed check even when the rest of the line names the narration source correctly.

- For a Douyin poetry video, replace a failed scope line with the exact approved sentence 文案、画面、字幕是 Muse 做的，旁白是豆包 TTS。

- Compare the replacement line character by character with the approved sentence 文案、画面、字幕是 Muse 做的，旁白是豆包 TTS。 and rewrite it when any character differs.

- Check the scope line again after any edit to the draft.

- Hold the draft and do not deliver it when 全自动制作 still appears anywhere in the final draft after the replacement.

## Correct and confirm before delivery

- Compare the final draft word by word against the scoped parts, and rewrite any sentence that still implies an unverified part.

- Show the user the scoped wording and the parts it covers before the user posts, so the user can spot a remaining overclaim before publication.

- Ask the user whether an earlier version was already posted when you find an overclaim, because a correction to a new draft does not retract a posted version.

- Deliver the verbatim prompt or copy the user asked for alongside the scoped wording, without reintroducing the broad claim in the surrounding text.

## Alternatives for better results

- Use a neutral description of the finished video when the production record is missing, and describe what the viewer will see rather than who produced each part.

- Offer a shorter claim that names only the verified parts when the user wants a punchy line, instead of stretching one verified part to cover the whole work.
